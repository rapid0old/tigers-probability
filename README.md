# 阪神 試合確率チェッカー v0.4

2026年の12球団・選手別の初期能力係数を内蔵し、試合中の得点確率・得点期待値・阪神勝率をシミュレーションするPWAです。

## v0.4 の変更
- CSVを読み込まなくても、起動直後から選手設定と確率表示が動作
- 2026年8月上旬スナップショットから主要打者150人・主要投手99人の派生係数を内蔵
- 打者はwOBAを基にした打撃力係数、投手はFIPを基にした失点しやすさ係数
- 少ない打席・投球回はリーグ平均へ縮約
- その日の実際の打順を9人設定可能
- 現在/次打者と現在投手を現在の半イニングの得点指標へ反映
- 残り試合は12球団の攻撃・投手係数を使ってシミュレーション
- 選手モデルでエラーが起きても、NPB 24状況ベースラインへ自動フォールバック
- 「次の半回」でアウト・走者を自動リセット
- 外部API・広告・トラッキング・外部JavaScriptなし

## データ
### 得点確率・得点期待値のベースライン
Baseball Explorer の 2023–2025 NPB 24状況集計。

### 初期選手モデル
NPB Data Bank が公開する2026年成績を基に、アプリ用の正規化・縮約係数を算出しています。
元の生データ表そのものはアプリに同梱していません。

### 任意の詳細更新
ProEyeKyuu（プロEYE球）の2026年選手打撃・投手CSVを利用者が端末内に読み込むと、
1B/2B/3B/HR/BB/HBP/K等を使う詳細打席イベントモデルへ切り替わります。
ProEyeKyuu はデータについて “Use the data as you please” と案内しています。

GitHub Pages は main ブランチ / (root) を公開してください。
