# 阪神 試合確率チェッカー v0.3

2026年の12球団・選手別成績を端末内に読み込み、試合中の得点確率・得点期待値・阪神勝率をシミュレーションするPWAです。

## v0.3
- 対戦相手を12球団から選択
- 2026年の打者・投手CSVを端末内に読み込み
- 打順9人を設定
- 現在/次打者と現在投手を反映
- 打者・投手の小標本をリーグ平均へ縮約
- 打席ごとのイベントシミュレーション
- 母親向けに読み込み済みデータをJSONとして書き出し/共有
- 「次の半回」でアウト・走者を自動リセット
- 外部API・広告・トラッキング・外部JavaScriptなし

## 2026選手データ
ProEyeKyuu（プロEYE球）のダウンロード可能な選手打撃成績・選手投手成績を想定しています。
アプリ内には選手CSVを同梱せず、利用者が自分の端末に読み込みます。

https://proeyekyuu.com/ja/player-batting-stats-jp/
https://proeyekyuu.com/ja/player-pitching-stats-jp/
