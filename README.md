# 阪神 試合確率チェッカー v0.6 試用版

2026年の12球団・選手別の初期能力係数を内蔵し、試合中の得点確率・得点期待値・阪神勝率をシミュレーションするPWAです。

## v0.6 試用版の変更
- ボール0-3、ストライク0-2のカウント入力を追加
- 現在カウントから四球・三振・インプレーの到達確率を補正し、次打席予測へ反映
- カウント補正を現在の半回の得点確率・得点期待値・阪神勝率へ反映
- 打席終了、次打者、半回変更時にカウントを0-0へ自動リセット
- 画面下に得点確率・得点期待値・阪神勝率・次打席予測の固定帯を追加
- 固定帯の各項目を押すと、大きな詳細表示を開く
- Service Workerのキャッシュ名を `tigers-probability-v0.6-trial` に更新

## v0.5 試用版の変更
- 表/裏、イニング、次の半回の変更時にアウト・走者をリセット
- 阪神の初期打順を「近本、中野、森下、佐藤、大山、前川、坂本、元山、投手」に設定
- 阪神の現在投手を選ぶと9番が「投手」枠へ自動設定
- 元山飛優を初期データに追加
- v0.4に残っていたローマ字表示をNPB公式ロスターの日本語表記へ更新
- 打順・投手・走者の候補を読みベースで並び替え
- 一塁、二塁、三塁の走者を選手として設定可能
- 凡退、三振、四死球、単打、二塁打、三塁打、本塁打の入力で走者・得点・アウト・次打者を自動更新
- Undoで直前の打席進行を取り消し
- 現在打者 x 現在投手の次打席予測を表示
- Service Workerのキャッシュ名を `tigers-probability-v0.5-trial` に更新

## 既存モデル
- 起動直後から選手設定と確率表示が動作
- 2026年8月下旬確認の主要打者151人・主要投手99人の派生係数を内蔵
- 打者はwOBAを基にした打撃力係数、投手はFIPを基にした失点しやすさ係数
- 少ない打席・投球回はリーグ平均へ縮約
- 得点確率・得点期待値・阪神勝率は従来のv0.4ロジックを維持
- 選手モデルでエラーが起きても、NPB 24状況ベースラインへ自動フォールバック
- 外部API・広告・トラッキング・外部JavaScriptなし

## データ出典
### 得点確率・得点期待値のベースライン
Baseball Explorer の 2023-2025 NPB 24状況集計。

### 内蔵選手名
NPB.jp 2026年度選手一覧、および阪神タイガース公式 2026選手プロフィールを確認しています。

### 初期選手係数
NPB公式の2026個人成績・チーム成績、およびv0.4内蔵係数を基にした派生値です。生の成績表は同梱せず、正規化・縮約した係数のみを内蔵しています。

### カウント補正
[MLB公式 Statcast Glossary](https://www.mlb.com/glossary/statcast/catcher-framing)が示す2025年の1-0後と0-1後のOPS差を方向性の確認に使っています。NPBのカウント別実測値とは区別し、四球・三振・インプレーへの到達過程と打者有利/投手有利を保守的に反映する試用係数です。

### 任意の詳細更新
利用者が公開データから作成した2026年の選手打撃・投手CSVを端末内に読み込むと、1B/2B/3B/HR/BB/HBP/K等を使う詳細打席イベントモデルへ切り替わります。
