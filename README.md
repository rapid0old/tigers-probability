# 阪神 試合確率チェッカー v1.1 試用版

2026年の12球団・選手別の初期能力係数を内蔵し、試合中の得点確率・得点期待値・阪神勝率をシミュレーションするPWAです。

## v1.1 試用版の変更
- 9回以降の表終了時、裏終了時、サヨナラ時にホーム・ビジターと得点を判定して試合を終了
- 阪神勝利時は「とらほー🐯!!」、敗戦時は「まけほー……」、引き分け時は「引き分け」を結果ダイアログへ表示
- 結果ダイアログへ「戻る」「次の試合へ」を追加。次の試合では保存済み相手打順などを維持して試合状態を初期化
- 画面左下にUndo、右下にRedoを常設し、打席結果・カウント・走者・得点・投手疲労・選手変更などを履歴化
- 打席結果のUndo・Redoでは、対応する端末内観戦記録も同時に取り消し・復元
- 現在打者の前へ打順番号を表示
- 固定確率帯の「次打席」詳細で、最頻結果の直下に凡退＋三振のトータルアウト確率を表示
- Service Workerのキャッシュ名を `tigers-probability-v1.1-trial` に更新

## v1.0 試用版の変更
- NPB公式の2026年現役支配下選手名簿を静的スナップショット化し、12球団842人を選択可能に変更
- 個人成績を内蔵していない選手向けに、各球団の野手平均・投手平均を明示的な代替データとして追加
- 打順、現在投手、代打、代走、投手交代、走者の各選択欄に共通の選手検索を追加
- 塁表示の直下に現在打者・現在投手・走者をまとめ、折りたたみ可能に変更
- 各走者へ進塁・盗塁ボタンを追加。進塁先が埋まっている場合は手動補正用の走者入れ替えに対応
- 打席結果へ併殺打・エラーを追加し、打者送り・アウト・走者・得点を連動
- 投手の投球数を10球単位で設定し、先発・救援別の保守的な疲労補正を次打席予測、得点予測、勝率へ反映
- 試合状態を端末内へ自動保存し、再読み込み後に復元。直前動作も画面に表示
- 観戦打席データからB-Sカウントを除外。盗塁成否は走力補正用の別記録として保存
- 全ボタンに押下フィードバックを追加
- Service Workerのキャッシュ名を `tigers-probability-v1.0-trial` に更新

## v0.9 試用版の変更
- 打席結果ボタンから入力した観戦データを端末内へ保存
- 内蔵または手動読込したスナップショットを基盤に、観戦結果を打者・投手・同一対戦の追加サンプルとして反映
- 少数打席で確率が暴れないよう、基準約48打席分を残す縮約方式を採用
- 観戦学習を次打席予測、この回の得点確率・得点期待値、阪神勝率へ反映
- 試合日、観戦記録ON/OFF、確率反映ON/OFF、学習件数と最終入力日を表示
- Undoで直前の打席進行と対応する観戦ログを同時に取り消し
- 観戦データのJSON書き出し・読み込み・一括破棄に対応
- 新しい詳細データの読込、または内蔵スナップショット日付の更新時に旧学習データを自動破棄
- 送りバントは観戦履歴へ保存する一方、打撃結果の確率学習からは除外
- Service Workerのキャッシュ名を `tigers-probability-v0.9-trial` に更新

## 既存モデル
- 起動直後から選手設定と確率表示が動作
- 2026年8月22日確認の主要選手に、阪神の控え野手13人・救援投手10人の派生係数を追加
- 打者はwOBAを基にした打撃力係数、投手はFIPを基にした失点しやすさ係数
- 少ない打席・投球回はリーグ平均へ縮約
- 得点確率・得点期待値・阪神勝率は従来のv0.4ロジックを維持
- 選手モデルでエラーが起きても、NPB 24状況ベースラインへ自動フォールバック
- 外部API・広告・トラッキング・外部JavaScriptなし

## データ出典
### 得点確率・得点期待値のベースライン
Baseball Explorer の 2023-2025 NPB 24状況集計。

### 内蔵選手名
NPB.jp 2026年度選手一覧、および阪神タイガース公式 2026選手プロフィールを確認しています。

### 初期選手係数
NPB公式の2026個人成績・チーム成績、およびv0.4内蔵係数を基にした派生値です。成績表そのものは同梱せず、正規化・縮約した係数と表示・計算に必要な最小限の集計値を内蔵しています。

### 阪神の控え・救援データ
[NPB公式 2026阪神個人打撃成績](https://npb.jp/bis/2026/stats/idb1_t.html)、[NPB公式 2026阪神個人投手成績](https://npb.jp/bis/2026/stats/idp1_t.html)を2026年8月22日時点で確認し、少ない打席・投球回を平均へ縮約した派生係数のみを内蔵しています。役割表示は同日時点のセーブ・ホールドと登板状況に基づく試用上の区分です。

### カウント補正
[MLB公式 Statcast Glossary](https://www.mlb.com/glossary/statcast/catcher-framing)が示す2025年の1-0後と0-1後のOPS差を方向性の確認に使っています。NPBのカウント別実測値とは区別し、四球・三振・インプレーへの到達過程と打者有利/投手有利を保守的に反映する試用係数です。

### 任意の詳細更新
利用者が公開データから作成した2026年の選手打撃・投手CSVを端末内に読み込むと、1B/2B/3B/HR/BB/HBP/K等を使う詳細打席イベントモデルへ切り替わります。

### 観戦データ学習
打席結果ボタンで入力した試合日・打者・投手・カウント・結果を、この端末のブラウザ内だけに保存します。データは外部へ送信せず、基準スナップショットを置き換えずに追加サンプルとして縮約して使います。新しい基準データへ切り替えた場合は、期間の二重計上を避けるため以前の観戦学習を破棄します。四死球ボタンはBB/HBPの合算として扱い、送りバントは打撃結果の確率分布へ含めません。

GitHub Pages は main ブランチ / (root) を公開してください。

### 現役支配下選手スナップショット
[NPB公式 現役選手一覧](https://npb.jp/bis/players/active/index.html)を2026年8月25日に確認し、育成選手を除く12球団842人の選手名・守備区分だけを静的に内蔵しています。ページ表示時の外部API通信やスクレイピングは行いません。個人成績がない選手は、根拠のない個人差を付けず同球団平均を使います。

### 投手疲労補正
[MLB公式 Pitch Count](https://www.mlb.com/glossary/standard-stats/number-of-pitches)、[MLB公式 Third Time Through the Order Penalty](https://www.mlb.com/glossary/miscellaneous/third-time-through-the-order-penalty)、[投球疲労の系統レビュー](https://pmc.ncbi.nlm.nih.gov/articles/PMC6673423/)、[75球前後からの下肢神経筋疲労を調べた2025年研究](https://pubmed.ncbi.nlm.nih.gov/40815189/)を方向性の根拠にしています。個人別の断定はせず、先発は40球以降、救援は20球以降を10球単位で段階補正する保守的な試用係数です。
